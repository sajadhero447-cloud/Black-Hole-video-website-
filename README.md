 Digital Black Hole Background Website

موقع ويب تجريبي مصمم خصيصاً لعرض تأثير بصري رائع لثقب أسود يتحرك كخلفية حية للموقع، تم تنفيذه ببساطة واحترافية باستخدام *HTML5* و *CSS3*

مميزات المشروع (Features)
* خلفية فيديو حية ومتحركة بملء الشاشة (Full-screen background)
* تصميم نظيف وخفيف بدون إبطاء لصفحة الويب
* متوافق مع جميع المتصفحات والأجهزة بفضل خصائص الـ HTML5 الحديثة.


🛠️ التقنيات المستخدمة (Tech Stack)
*HTML5* (لهيكل الصفحة وعنصر الفيديو) 
*CSS3* (لتنسيق الخلفية وثباتها فوق الشاشة)

طريقة التشغيل محلياً (How to Run Locally) :


  1- حمل ملف ZIP الخاص،بملفات الموقع
  2- فك ضغط الملف عن طريق فتح ملف ZIP ثم استخراج للملفات الي بداخله،او الاسهل ارفع الملف ZIP كامل لأي محرر اكواد مثل spck editor
  3- واخيرا ارفعه الملفات لأي استضافه مثل Netlify drop او تفتح الموقع مباشره من محرر الاكواد ب Spck editor
